patched or rerun under the same identity.

Success requires exact role/claim custody, ten counted calls, three disposable
creator-authorized test acceptances, scene-change isolation, immutable source
and disposable database hashes, clean thread archival, unchanged D-180, and
zero production or installed-client effects.

the creator's target. Those are measured by this canary only after separate
creator authorization.
