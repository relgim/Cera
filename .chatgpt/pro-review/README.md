# CERA ChatGPT Pro Checkpoint Reviews

This tree contains checkpoint review handoffs governed by
`docs/authority/CODEX_PROGRESS_REVIEW_PROTOCOL.md`.

Each checkpoint directory contains Codex's `REQUEST.md` and may later contain
ChatGPT Pro's `PRO_RESPONSE.md`. Requests cite the exact local checkpoint SHA,
real diff, source, tests, provider/database effects, and remaining uncertainty.
ChatGPT Pro reviews independently and proposes the next bounded tranche;
neither its response nor Codex's recommendation silently grants creator
authority.

After sending a request, Codex stops. Silence is not authorization.
