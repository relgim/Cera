# Modular Composer prompt sources

The immutable ChatGPT Pro authoring package is preserved under `provenance/`.
`runtime_v2/MANIFEST.json` is the CERA-owned, hash-bound adaptation used by the
current ordinary development Composer prompt
`cera.deepseek_scene_composer_prompt.v22`.

Python selects and orders stable core, one Depth profile, one Adult rendering
profile, one interaction-topology profile, and one scene-function profile.
Dynamic source, validated plan, evidence, selected-character context, and the
request schema remain canonical user JSON; they are not copied into stable
module prose.

Depth and Adult mode do not select events, consent, cast, relationship state,
or physiology. SequencePlan entries are broad causal blocks; hidden writer
scaffolding is not an extra event or paragraph obligation. The Composer still
makes one call. There is no Detailer, retry, or fallback.

The live route is limited to ordinary/relationship human testing. Adult ON/EX
publication remains closed even though provider-free prompt/catalog contracts
exist.
